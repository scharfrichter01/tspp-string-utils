# String Utilities

## Подробное описание

String Utilities — консольная утилита и библиотека на C++ для обработки текстовых данных, реализующая набор базовых строковых операций:

| Функция | Назначение |
|----------|------------|
| `trim` | Удаление пробельных символов в начале и в конце строки |
| `split` | Разбиение строки на вектор подстрок по заданному символу-разделителю |
| `replace` | Замена всех вхождений одной подстроки на другую |
| `is_palindrome` | Проверка, читается ли строка одинаково слева направо и справа налево |
| `is_anagram` | Проверка, состоят ли две строки из одинакового набора символов |
| `word_count` | Подсчёт количества слов (непробельных последовательностей) в строке |

Программа демонстрирует работу утилит в интерактивном демонстрационном режиме при запуске исполняемого файла.

Проект разработан в рамках лабораторной работы и демонстрирует:
- сборку через CMake;
- модульное тестирование GoogleTest;
- настройку CI/CD на GitLab;
- автоматическую генерацию и публикацию документации Doxygen.

## Сборка ПО

```bash
# 1. Клонирование репозитория и подтягивание подмодулей (GoogleTest)
git clone https://vgit.mirea.ru/najmudin051/tspp-string-utils.git
cd tspp-string-utils
git submodule update --init --recursive

# 2. Конфигурация и сборка
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

# 3. Запуск модульных тестов
cd build && ctest --output-on-failure && cd ..

# 4. (Опционально) Сборка документации Doxygen локально
doxygen Doxyfile
# Готовая HTML-документация: doc/html/index.html
```

## Запуск

### Режим 1 — демонстрационный запуск

```bash
./build/string_utils_app
```

Программа выводит примеры работы всех шести функций с тестовыми данными.

### Режим 2 — использование как библиотеки

```cpp
#include "string_utils.h"
#include <iostream>
#include <string>

int main() {
    using namespace StringUtils;

    std::string text = "   hello world   ";

    std::cout << trim(text) << "\n";
    std::cout << word_count(text) << "\n";
    std::cout << is_palindrome("топот") << "\n";

    return 0;
}
```

## Публичный API библиотеки StringUtils

| Функция | Назначение |
|----------|------------|
| `trim(str)` | Возвращает строку без крайних пробельных символов |
| `split(str, delimiter)` | Возвращает `std::vector<std::string>`, разбитый по разделителю |
| `replace(str, from, to)` | Возвращает строку с заменёнными подстроками |
| `is_palindrome(str)` | Возвращает `true`, если строка является палиндромом |
| `is_anagram(str1, str2)` | Возвращает `true`, если строки являются анаграммами |
| `word_count(str)` | Возвращает количество слов в строке |

## Образы для сборок CI/CD

Сборки в конвейере непрерывной интеграции выполняются в официальном образе `ubuntu:22.04`, который автоматически устанавливает необходимые зависимости (`cmake`, `g++`, `doxygen`, `graphviz`) на этапе `before_script`.
