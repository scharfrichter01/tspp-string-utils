## 📋 Описание
Проект реализует набор строковых утилит на C++:
- **trim()** — удаление пробельных символов по краям строки
- **split()** — разбиение строки по разделителю
- **replace()** — замена подстрок
- **is_palindrome()** — проверка на палиндром
- **is_anagram()** — проверка на анаграмму
- **word_count()** — подсчет слов в строке

## 📦 Установка и сборка

### Локальная сборка
```bash
# Клонируйте репозиторий
git clone https://vgit.mirea.ru/najmudin051/tspp-string-utils.git
cd tspp-string-utils

# Инициализируйте подмодули (GoogleTest)
git submodule update --init --recursive

# Создайте папку build и соберите проект
mkdir build && cd build
cmake ..
cmake --build .

# Запустите программу
./string_utils_app

# Запустите тесты
ctest --output-on-failure
